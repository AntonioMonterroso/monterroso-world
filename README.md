# Monterroso World

Centro de mando personal (PWA): horario, trabajos, música, púlpito, finanzas, ejercicio, bóveda cifrada y más.

- Front: Vite + React + TypeScript + Tailwind, PWA.
- Backend: Supabase (Postgres, Auth, Realtime, Storage, Edge Functions).
- Deploy: GitHub Pages desde `main`.

```bash
npm install
npm run dev
```

Variables (`.env.local`, nunca se suben): `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.
